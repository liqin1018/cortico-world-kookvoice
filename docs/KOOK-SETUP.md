# 从零创建一个 KOOK 机器人

这个插件要靠一个 **KOOK 机器人账号**进语音频道。全程免费，大约 5 分钟。

> 下面的菜单名称以 KOOK 开发者平台为准，界面可能随版本微调。

---

## 开始前

你需要：

- 一个 KOOK 账号
- 一个**你自己的服务器**（要有管理权限）
- 机器人会以**独立账号**的身份出现在服务器里 —— 它不是你的小号，是另一个成员

---

## 第 1 步：进开发者平台

打开 <https://developer.kookapp.cn/>，用 KOOK 扫码或账号登录。

第一次进可能要补一下开发者资料（昵称之类），按提示填完即可。

---

## 第 2 步：创建应用

1. 左侧点「**应用**」
2. 右上角「**新建应用**」
3. 填名字（比如 `我的桌宠`）、简介、传个头像
4. 保存

> 名字就是机器人在服务器里显示的名字，可以随便起。
> 这个插件只用到应用里的「机器人」能力，其他都不用配。

---

## 第 3 步：拿 Token

进入刚创建的应用 → 左侧或顶部找到「**机器人**」页签。

那里有一串 **Token**（也可能叫「令牌」），点「复制」。

```
xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

**这串东西就是插件的「KOOK 机器人令牌」。**

> ⚠️ Token 等于机器人的密码。不要发到群里、不要提交到 GitHub。
> 如果泄露了，同一页面有「重置」按钮，重置后旧的就失效。

---

## 第 4 步：邀请机器人进你的服务器

在「机器人」页面找「**邀请链接**」或「**添加到服务器**」：

1. 勾选需要的权限（见下表）
2. 复制生成的邀请链接
3. 在浏览器打开 → 选择你的服务器 → 授权

### 需要的权限

| 权限 | 为什么 |
|---|---|
| **查看频道** | 不然它看不到你的语音频道列表 |
| **加入语音频道** | 核心 —— 没这个进不去 |
| 发送消息（可选） | 如果你想让它也能在文字频道回话 |

如果勾选时找不到「加入语音频道」，说明 KOOK 把它归在「语音」分类下，展开找一下。

---

## 第 5 步：验证 Token 能用

打开终端（Windows 用 PowerShell 或 CMD），把 `<你的token>` 换成刚才复制的：

```bash
curl -H "Authorization: Bot <你的token>" https://www.kookapp.cn/api/v3/user/me
```

**成功**会返回一段 JSON，里面有机器人的 id、username：

```json
{"code":0,"message":"操作成功","data":{"id":"1234567890","username":"我的桌宠",...}}
```

**失败**会是：

```json
{"code":40100,"message":"token 无效"}
```

看到 40100 就是 Token 抄错了，回第 3 步重来。

> 也可以跳过这一步，直接把 Token 填进插件面板 → 「频道」页 → 点「检测」。
> 令牌有问题那里会直接报错。

---

## 第 6 步：填进插件

回到 Coopanion → World 扩展 → KOOK 语音 → 「频道」页 → 最上面的令牌框 → 粘贴 → 「保存」。

然后点「检测」，应该就能看到你服务器里的语音频道了。

---

## 常见问题

**Q：检测时报 `guild_id does not exist`**

机器人已经进服务器了，但 Token 对不上这台服务器。
检查：Token 是不是另一个应用的？机器人是不是真的被邀请进这个服务器了？

**Q：检测能看到频道，但进频道失败**

权限不够。回第 4 步，确认勾了「加入语音频道」，重新邀请一次（邀请链接可以重复用，已有权限会合并）。

**Q：机器人进了服务器，但列表里看不到**

服务器成员列表默认只显示在线成员。机器人上线后才会出现；离线时可能在「离线成员」里。

**Q：能不能用我自己的账号当机器人？**

不能。KOOK 的机器人必须是应用身份，个人账号没有 Token 机制。

**Q：一个机器人能进几个服务器？**

可以进多个。这个插件一次只服务一个服务器（在面板上「检测」时选的那个）。
